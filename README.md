# Over the Rock — Daily AI News Briefing

**Live site: [overtherock.frederickstoney.com](https://overtherock.frederickstoney.com)**

A daily news briefing generated by an LLM with live web search, written like a friend catching you up over coffee instead of a wire-service headline dump.

## How it works

- A Vercel Cron job (`api/cron`) runs once a day, calls Gemini with grounded web search, and asks it to summarize global news and internet culture from the last 72 hours in a casual, no-jargon voice.
- The result is cached in Redis (Upstash) as a single `daily_cache` record.
- The frontend (SvelteKit) reads that cached record on each request — no per-visitor LLM calls, so the site stays fast and cheap to run.
- Cron requests are authenticated with a bearer secret so only Vercel's scheduler can trigger a regeneration.

## Stack

SvelteKit 2 · Svelte 5 · TypeScript · Google Gemini (`@google/genai`) · Upstash Redis · Vercel (hosting + cron)

## Running locally

```sh
npm install
npm run dev
```

Requires `GOOGLE_API_KEY`, `KV_REST_API_URL`, `KV_REST_API_TOKEN`, and `CRON_SECRET` in `.env` — see `src/routes/api/cron/+server.ts` for how each is used. Without Redis configured, the homepage falls back to a placeholder message instead of failing.
